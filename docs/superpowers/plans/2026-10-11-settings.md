# Settings Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let users change model weights and thresholds from a Settings page. Values are saved in
`data/settings.json` and applied to every page.

**Architecture:** A pydantic `UserSettings` model (flat keys, defaults = today's constants) is
loaded from `data/settings.json` on each request. It is passed into `get_context`, which keys its
cache on the settings fingerprint and stores them on `LeagueContext.tuning`. From there the
values are passed **explicitly** to the projection engine, matchup cells, injury availability,
verdict, advisor and trade code. Each of those gets a parameter whose default is the old constant,
so the backtest and existing tests behave exactly as before. A `/settings` GET/PUT/DELETE API
feeds a React page built from a per-field schema.

**Tech Stack:** FastAPI + pydantic v2, DuckDB, polars (backend; `uv run pytest`); Vite + React +
TanStack Query/Router, generated hey-api client, vitest (frontend).

**Spec:** `docs/superpowers/specs/2026-10-11-settings-design.md`

## Global Constraints

- Defaults must equal today's constants exactly (QB .25 / RB .5 / WR .25 / TE 0 / K .25 / DEF .75
  matchup alpha; usage weight 0.5; shrink 8; gap 10 pts / 10%; startable QB24 RB60 WR60 TE24;
  10 per tier; Questionable 0.85; Doubtful 0.25; IR 4 weeks; waiver 1.5; start/sit 1.0; easy 1.08;
  tough 0.92; trade accept 8.0; lean 2.0).
- `data/settings.json` holds only non-default values. A missing or broken file never raises; it
  falls back to defaults with a warning.
- Do not mutate module globals. Every new parameter defaults to the existing constant.
- The backtest (`models/`) is untouched and keeps using the defaults.
- Python files on this machine: keep LF line endings (edit with the Edit tool; if scripting, use
  `read_bytes().decode().replace("\r\n", "\n")`).
- Commits: **no** `Co-Authored-By` / "Generated with" lines. Run `git push` after every commit.
- Run backend tests from `backend/`: `uv run pytest <path> -q`. Full suite from the repo root:
  `python tasks.py test`.
- After any change to API models, run `python tasks.py gen-api` from the repo root.

```python
"""User-adjustable model weights and thresholds, stored in data/settings.json.

Defaults are the values the app was tuned with (projection fields by the walk-forward backtest).
The file holds only values that differ from the defaults, so improved defaults still reach users
who never touched a field. A broken file never breaks the app: it falls back to the defaults with
a warning that the Settings page shows.
"""

from __future__ import annotations

import json
import os
import tempfile
from collections.abc import Mapping
from pathlib import Path

from pydantic import BaseModel, ConfigDict, Field, ValidationError, model_validator

from projections.base import IR_WEEKS_MISSED, STATUS_THIS_WEEK
from projections.baseline import SHRINK_GAMES, W_USAGE
from signals import advisor, trade
from signals.schedule import MATCHUP_ALPHA
from signals.targets import TOP_N
from signals.verdict import GAP_MIN_POINTS, GAP_MIN_SHARE, STARTABLE_RANK

PROJ, VERDICT, INJ, ADV = "Projections", "Buy/sell & targets", "Injuries", "Advisor & trades"
GROUPS = (PROJ, VERDICT, INJ, ADV)


def _f(default, lo, hi, group: str, label: str, help: str, tuned: bool = False):  # noqa: A002
    return Field(
        default, ge=lo, le=hi, title=label, description=help,
        json_schema_extra={"group": group, "tuned": tuned},
    )  # fmt: skip


def _alpha(pos: str):
    return _f(
        MATCHUP_ALPHA[pos], 0, 1.5, PROJ, f"{pos} matchup strength",
        f"How much an easy or hard opponent moves a {pos}'s weekly projection (0 = ignore matchups).",
        tuned=True,
    )  # fmt: skip


def _startable(pos: str):
    return _f(
        STARTABLE_RANK[pos], 1, 100, VERDICT, f"{pos} startable depth",
        f"Only {pos}s we rank this high or better can be a buy (and only ones the market ranks this "
        "high can be a sell). Deeper players are always a hold.",
    )  # fmt: skip


class UserSettings(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True)

    usage_weight: float = _f(
        W_USAGE, 0, 1, PROJ, "Usage weight",
        "Share of a projection from usage (targets, carries, snaps); the rest is season scoring rate.",
        tuned=True,
    )  # fmt: skip
    shrink_games: int = _f(
        SHRINK_GAMES, 0, 17, PROJ, "Early-season shrink (games)",
        "How many games of last season this season's scoring rate is blended with. Higher = trust "
        "this season less early on.",
        tuned=True,
    )  # fmt: skip
    matchup_alpha_qb: float = _alpha("QB")
    matchup_alpha_rb: float = _alpha("RB")
    matchup_alpha_wr: float = _alpha("WR")
    matchup_alpha_te: float = _alpha("TE")
    matchup_alpha_k: float = _alpha("K")
    matchup_alpha_def: float = _alpha("DEF")

    gap_min_points: float = _f(
        GAP_MIN_POINTS, 0, 50, VERDICT, "Buy/sell gap (points)",
        "Minimum rest-of-season points between our projection and the market's price for a buy or sell.",
    )  # fmt: skip
    gap_min_share: float = _f(
        GAP_MIN_SHARE, 0, 0.5, VERDICT, "Buy/sell gap (share)",
        "Or this share of the market's price, whichever is larger (0.10 = 10%).",
    )  # fmt: skip
    startable_qb: int = _startable("QB")
    startable_rb: int = _startable("RB")
    startable_wr: int = _startable("WR")
    startable_te: int = _startable("TE")
    targets_per_tier: int = _f(
        TOP_N, 3, 25, VERDICT, "Buy targets per tier",
        "How many players the Buy targets page lists in each tier (starters, bench depth).",
    )  # fmt: skip

    play_chance_questionable: float = _f(
        STATUS_THIS_WEEK["Questionable"], 0, 1, INJ, "Questionable: chance he plays",
        "This week's projection for a Questionable player is multiplied by this.",
    )  # fmt: skip
    play_chance_doubtful: float = _f(
        STATUS_THIS_WEEK["Doubtful"], 0, 1, INJ, "Doubtful: chance he plays",
        "This week's projection for a Doubtful player is multiplied by this.",
    )  # fmt: skip
    ir_weeks_out: int = _f(
        IR_WEEKS_MISSED, 0, 17, INJ, "Weeks out on IR / PUP",
        "Weeks a player on IR, PUP or NFI is assumed to miss when there's no return date.",
    )  # fmt: skip

    waiver_min_gain: float = _f(
        advisor.WAIVER_MIN_GAIN, 0, 10, ADV, "Waiver pickup: minimum gain (ppg)",
        "Suggest a free agent only if he beats the player he'd replace by this many points per game.",
    )  # fmt: skip
    start_sit_min_gain: float = _f(
        advisor.START_SIT_MIN_GAIN, 0, 10, ADV, "Start/sit: minimum gain (pts)",
        "Suggest a lineup swap only if it gains at least this many projected points this week.",
    )  # fmt: skip
    easy_schedule: float = _f(
        advisor.EASY_SCHEDULE, 1.0, 1.3, ADV, "Easy schedule cutoff",
        "Opponent index at or above this counts as an easy schedule (1.08 = 8% easier than average).",
    )  # fmt: skip
    tough_schedule: float = _f(
        advisor.TOUGH_SCHEDULE, 0.7, 1.0, ADV, "Tough schedule cutoff",
        "Opponent index at or below this counts as a tough schedule (0.92 = 8% harder than average).",
    )  # fmt: skip
    trade_accept_gain: float = _f(
        trade.ACCEPT_GAIN, 0, 50, ADV, "Trade: accept at (pts)",
        "A trade is an accept when your starting lineup gains at least this many ROS points.",
    )  # fmt: skip
    trade_lean_gain: float = _f(
        trade.LEAN_GAIN, 0, 50, ADV, "Trade: lean accept at (pts)",
        "Gains between this and the accept line are a lean accept; losses beyond it are a decline.",
    )  # fmt: skip

    @model_validator(mode="after")
    def _lean_below_accept(self) -> UserSettings:
        if self.trade_lean_gain > self.trade_accept_gain:
            raise ValueError("trade_lean_gain must be at most trade_accept_gain")
        return self

    @property
    def alpha(self) -> dict[str, float]:
        return {
            "QB": self.matchup_alpha_qb, "RB": self.matchup_alpha_rb, "WR": self.matchup_alpha_wr,
            "TE": self.matchup_alpha_te, "K": self.matchup_alpha_k, "DEF": self.matchup_alpha_def,
        }  # fmt: skip

    @property
    def startable(self) -> dict[str, int]:
        return STARTABLE_RANK | {
            "QB": self.startable_qb, "RB": self.startable_rb,
            "WR": self.startable_wr, "TE": self.startable_te,
        }  # fmt: skip

    def fingerprint(self) -> str:
        return self.model_dump_json()


def describe_error(exc: Exception) -> str:
    if isinstance(exc, ValidationError):
        e = exc.errors()[0]
        where = ".".join(str(x) for x in e["loc"]) or "settings"
        return f"{where}: {e['msg']}"
    return str(exc)


def load(path: Path) -> tuple[UserSettings, str | None]:
    if not path.exists():
        return UserSettings(), None
    try:
        raw = json.loads(path.read_text(encoding="utf-8"))
        if not isinstance(raw, dict):
            raise ValueError(f"{path.name} must contain a JSON object")
        return UserSettings.model_validate(raw), None
    except (OSError, ValueError) as exc:  # JSONDecodeError and ValidationError are ValueErrors
        return UserSettings(), (
            f"{path.name} couldn't be used ({describe_error(exc)}). Using defaults; "
            "saving will replace the file."
        )


def save(path: Path, s: UserSettings) -> None:
    """Write only non-default values, atomically (temp file + rename)."""
    path.parent.mkdir(parents=True, exist_ok=True)
    fd, tmp = tempfile.mkstemp(dir=path.parent, prefix=".settings-", suffix=".json")
    try:
        with os.fdopen(fd, "w", encoding="utf-8", newline="\n") as f:
            json.dump(s.model_dump(exclude_defaults=True), f, indent=2, sort_keys=True)
            f.write("\n")
        os.replace(tmp, path)
    except BaseException:
        Path(tmp).unlink(missing_ok=True)
        raise


def apply(current: UserSettings, changes: Mapping[str, float]) -> UserSettings:
    unknown = sorted(set(changes) - set(UserSettings.model_fields))
    if unknown:
        raise ValueError(f"unknown setting: {', '.join(unknown)}")
    return UserSettings.model_validate(current.model_dump() | dict(changes))


def _bound(info, attr: str) -> float:
    return next(getattr(m, attr) for m in info.metadata if hasattr(m, attr))


def field_schema(s: UserSettings) -> list[dict]:
    out = []
    for key, info in UserSettings.model_fields.items():
        extra = info.json_schema_extra or {}
        out.append(
            {
                "key": key,
                "group": extra["group"],
                "label": info.title,
                "help": info.description,
                "default": info.default,
                "min": _bound(info, "ge"),
                "max": _bound(info, "le"),
                "integer": info.annotation is int,
                "tuned": bool(extra.get("tuned")),
                "value": getattr(s, key),
            }
        )
    return out
```

def availability(
    injury_status: str | None,
    status: str | None,
    week: int,
    start: int,
    inj: InjuryAssumptions = DEFAULT_INJURY,
) -> float:
    """Expected fraction of a game the player suits up for in `week` (as of `start`)."""
    tags = {injury_status or "", status or ""}
    if tags & STATUS_LONG_TERM:
        return 0.0 if week < start + inj.ir_weeks else 1.0
    if week == start:
        p = inj.this_week(injury_status)
        return 1.0 if p is None else p
    return 1.0


def availability_note(
    injury_status: str | None, status: str | None, inj: InjuryAssumptions = DEFAULT_INJURY
) -> str | None:

    p = inj.this_week(injury_status)
    if p is not None:
        return f"{injury_status} this week ({round(p * 100)}% chance-weighted)"
    return None

```tsx
import { useMutation, useQuery, useQueryClient } from '@tanstack/react-query'
import { AlertTriangle, RotateCcw } from 'lucide-react'
import { useState } from 'react'
import { toast } from 'sonner'

import type { SettingFieldOut, SettingsOut } from '@/api'
import {
  getUserSettingsOptions,
  resetUserSettingsMutation,
  updateUserSettingsMutation,
} from '@/api/@tanstack/react-query.gen'
import { ErrorState, ListSkeleton, PageHeader } from '@/components/common/states'
import { Button } from '@/components/ui/button'
import { Card, CardContent, CardDescription, CardHeader, CardTitle } from '@/components/ui/card'
import { Input } from '@/components/ui/input'
import { Label } from '@/components/ui/label'
import { describeError } from '@/lib/errors'

const GROUP_NOTES: Record<string, string> = {
  Projections:
    'Defaults were picked by the walk-forward backtest (2022–25 seasons). Moving them away from the defaults can make projections less accurate.',
  'Buy/sell & targets': 'When a player gets a buy or sell call, and how the Buy targets page is cut.',
  Injuries: 'How much an injury designation discounts a player.',
  'Advisor & trades': 'How big an edge the advisor needs before it suggests a move.',
}

const fmt = (v: number) => String(Number(v.toFixed(3)))

function isValid(f: SettingFieldOut, v: number) {
  return !Number.isNaN(v) && v >= f.min && v <= f.max && (!f.integer || Number.isInteger(v))
}

function SettingRow({ field, value, onChange }: { field: SettingFieldOut; value: number; onChange: (v: number) => void }) {
  const id = `setting-${field.key}`
  const changed = value !== field.default
  const valid = isValid(field, value)
  return (
    <div className="grid gap-2 sm:grid-cols-[1fr_8rem] sm:items-start sm:gap-6">
      <div className="flex flex-col gap-1">
        <Label htmlFor={id}>{field.label}</Label>
        <p className="text-xs text-muted-foreground">{field.help}</p>
        <p className="text-xs text-muted-foreground">
          Default {fmt(field.default)} · allowed {fmt(field.min)}–{fmt(field.max)}
          {changed && (
            <>
              {' · '}
              <button
                type="button"
                className="underline underline-offset-2 hover:text-foreground"
                onClick={() => onChange(field.default)}
              >
                reset
              </button>
            </>
          )}
        </p>
      </div>
      <Input
        id={id}
        type="number"
        inputMode="decimal"
        min={field.min}
        max={field.max}
        step={field.integer ? 1 : 0.01}
        value={Number.isNaN(value) ? '' : value}
        aria-invalid={!valid}
        className={changed ? 'border-primary font-mono tabular-nums' : 'font-mono tabular-nums'}
        onChange={(e) => onChange(e.target.value === '' ? Number.NaN : Number(e.target.value))}
      />
    </div>
  )
}

function SettingsForm({ data }: { data: SettingsOut }) {
  const qc = useQueryClient()
  const [draft, setDraft] = useState<Record<string, number>>({})
  const done = (title: string) => () => {
    setDraft({})
    void qc.invalidateQueries()
    toast.success(title, { description: 'Every page now uses the new numbers.' })
  }
  const onError = (err: unknown) => toast.error(describeError(err).message, { description: describeError(err).hint })
  const save = useMutation({ ...updateUserSettingsMutation(), onSuccess: done('Settings saved'), onError })
  const reset = useMutation({ ...resetUserSettingsMutation(), onSuccess: done('Settings reset to defaults'), onError })

  const valueOf = (f: SettingFieldOut) => draft[f.key] ?? f.value
  const changes = Object.fromEntries(
    Object.entries(draft).filter(([k, v]) => v !== data.fields.find((f) => f.key === k)?.value),
  )
  const invalid = data.fields.some((f) => !isValid(f, valueOf(f)))
  const anyCustom = data.fields.some((f) => f.value !== f.default)
  const groups = [...new Set(data.fields.map((f) => f.group))]

  return (
    <div className="flex flex-col gap-6">
      {data.warning && (
        <Card className="border-destructive/50">
          <CardContent className="flex items-start gap-2 py-4 text-sm">
            <AlertTriangle className="mt-0.5 size-4 shrink-0 text-destructive" />
            {data.warning}
          </CardContent>
        </Card>
      )}
      {groups.map((g) => (
        <Card key={g}>
          <CardHeader>
            <CardTitle>{g}</CardTitle>
            {GROUP_NOTES[g] && <CardDescription>{GROUP_NOTES[g]}</CardDescription>}
          </CardHeader>
          <CardContent className="flex flex-col gap-6">
            {data.fields
              .filter((f) => f.group === g)
              .map((f) => (
                <SettingRow
                  key={f.key}
                  field={f}
                  value={valueOf(f)}
                  onChange={(v) => setDraft((d) => ({ ...d, [f.key]: v }))}
                />
              ))}
          </CardContent>
        </Card>
      ))}
      <div className="sticky bottom-0 flex flex-wrap items-center gap-3 border-t bg-background py-3">
        <Button
          disabled={invalid || Object.keys(changes).length === 0 || save.isPending}
          onClick={() => save.mutate({ body: changes })}
        >
          Save
        </Button>
        <Button variant="ghost" disabled={Object.keys(draft).length === 0} onClick={() => setDraft({})}>
          Discard changes
        </Button>
        <Button
          variant="outline"
          className="ml-auto"
          disabled={!anyCustom || reset.isPending}
          onClick={() => {
            if (window.confirm('Reset every setting to its default?')) reset.mutate({})
          }}
        >
          <RotateCcw /> Reset all
        </Button>
      </div>
      <p className="text-xs text-muted-foreground">Saved in {data.path}. Only changed values are written.</p>
    </div>
  )
}

export function SettingsPage() {
  const q = useQuery(getUserSettingsOptions())
  return (
    <div className="flex flex-col gap-6">
      <PageHeader
        title="Settings"
        description="Tune the model's weights and the thresholds behind buy/sell calls, injuries and advice. Changes apply to every page."
      />
      {q.isPending && <ListSkeleton rows={4} height="h-40" />}
      {q.isError && <ErrorState error={q.error} onRetry={() => void q.refetch()} />}
      {q.data && <SettingsForm data={q.data} />}
    </div>
  )
}
```
